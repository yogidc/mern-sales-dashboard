# Screenshots Directory

Add your application screenshots here:

## Required Screenshots:

1. **login.png** - Login/Register page
2. **dashboard.png** - Main dashboard view
3. **upload.png** - CSV upload interface
4. **charts.png** - Analytics charts view
5. **stats.png** - Statistics overview

## How to Take Screenshots:

1. Run your application (backend + frontend)
2. Take screenshots using:
   - Windows: `Win + Shift + S` (Snipping Tool)
   - Mac: `Cmd + Shift + 4`
   - Or use any screenshot tool

3. Save screenshots in this folder with the names above

## Tips:

- Use high resolution (at least 1920x1080)
- Show the full interface
- Make sure data is visible in charts
- Use PNG format for best quality
